# ПРАЙМ — конструктор чекапов

Русскоязычный MVP для хакатона: **веб-анкета → подбор пакета ПРАЙМ по правилам → выбор пакета и времени в демо-календаре → маршрут на один день → демо-отчёт в карте здоровья → напоминание о повторе**.

## Запуск

Нужен Python 3.10 или новее. Внешние библиотеки не требуются.

```powershell
cd C:\Users\bekza\Desktop\medhub\MedHub_CheckUp
python server.py
```

Откройте `http://127.0.0.1:8000`. Остановка: `Ctrl+C`.

Если порт 8000 занят, запустите сервер на другом порту:

```powershell
$env:MEDHUB_PORT = "8001"
python server.py
```

Тогда откройте `http://127.0.0.1:8001`.

## Как пройти демонстрацию

1. Введите возраст и пол. При желании отметьте жалобы, семейную историю и факторы образа жизни.
2. Нажмите «Получить рекомендацию». Сервер выберет программу по прозрачным правилам и вернёт причины на русском языке.
3. Просмотрите рекомендованный пакет, два других пакета и примерный маршрут на день. Цены демонстрационные: базовый — 59 900 ₸, расширенный — 89 900 ₸, «Сердце» — 69 900 ₸.
4. Выберите пакет, день и время в демо-календаре. Метки загрузки и ожидания созданы для показа сценария, к расписанию клиники сервис пока не подключён. Демо запись сохраняется в браузере и скачивается файлом `.ics`; настоящую запись подтверждает клиника.
5. Откройте демо-отчёт в карте здоровья. Данные анкеты, включая свободный ответ, сохраняются только в браузере; результаты анализов и заключение врача отмечены как ожидаемые.
6. Укажите дату и скачайте напоминание `.ics` для календаря. Через шесть месяцев предлагается обсудить с врачом необходимость нового чекапа; частоту обследований определяет врач.

## Правила подбора

- Жалобы на сердце или давление ведут к программе «Сердце».
- Семейная история сердечно-сосудистых заболеваний вместе с курением также ведёт к программе «Сердце».
- В остальных случаях программа выбирается по полу и возрасту: базовая до 40 лет, расширенная с 40 лет.
- При сильной боли в груди, выраженной одышке или внезапном ухудшении сервис прекращает подбор и советует обратиться за срочной помощью.
- Во время беременности программа согласуется с врачом.

Это демонстрационные правила предварительного подбора, а не медицинское назначение. Состав обследований, реальную стоимость, свободное время и маршрут подтверждает клиника. Показанные цены заданы для демонстрации и не являются официальным прайсом ПРАЙМ.

## Техническая структура

- `server.py` — HTTP-сервер и API: `GET /api/catalog`, `POST /api/recommend`.
- `domain.py` — каталог, проверка анкеты, правила выбора, причины и маршрут.
- `public/` — адаптивный интерфейс на русском языке.
- `tests/` — проверки основных сценариев.

Запуск тестов:

```powershell
python -m unittest discover -s tests -v
```

Исходный код распространяется по лицензии MIT.
